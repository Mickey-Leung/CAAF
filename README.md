# CAAF
Open-accessed code and data for the manuscript: Smart Sensor Placement: Correlation-Aware Attribution Framework (CAAF) for Real-world Data Modeling

The channel-flow velocity data used in the wall-shear stress estimation and the wall-normal velocity prediction applications are not included in this repository due to size limit but is available upon request.

For data inquiries and other questions related to this work, please contact the corresponding author through sleung@caltech.edu or szechaileung@outlook.com.
