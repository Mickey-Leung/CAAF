# CAAF
Open-accessed code and data for the manuscript: Data-driven Sensor Placement for Predictive Applications: A Correlation-Assisted Attribution Framework (CAAF)

The channel-flow velocity data used in the wall-normal velocity prediction application are not included in this repository but are available via Figshare (https://doi.org/10.6084/m9.figshare.31896294).

For data inquiries and other questions related to this work, please contact the corresponding author through sleung@caltech.edu or szechaileung@outlook.com.
